## 🎯 Purpose

The goal of this repository is to demonstrate not just the final outcome, but more importantly:

- How a problem or requirement was investigated;
- How the application logic and data structures were designed;
- Why a specific architectural approach was selected;
- How edge cases, validations, and tests were handled.

---

## 🧠 Engineering Philosophy

> "Do not fix the first symptom you see. Trace the system until you find the layer where reality diverges from expectation."

For backend development, databases, and system analysis, the investigation flow follows:

```text
User Input / Entry Point
   ↓
Business & Application Logic (Java)
   ↓
Domain Models (OOP)
   ↓
Persistence Layer (File I/O / SQL Database)
```
